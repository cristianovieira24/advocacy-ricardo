# Ricardo Nuno Fonseca & Associados — conceito de website

Conceito independente de website institucional, desenvolvido com informação pública confirmada em 1 de setembro de 2026. Não é o website oficial da sociedade.

## Executar localmente

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Verificações

```bash
npm run typecheck
npm run lint
npm run build
```

## Publicação

O projeto pode ser importado diretamente na Vercel. Enquanto for uma demonstração, mantenha `noindex` e o bloqueio em `app/robots.ts`. Só remova essas proteções após autorização da sociedade e validação de todo o conteúdo.

A composição possui comportamentos próprios para desktop, tablet, telemóvel e telemóvel pequeno. Em ecrãs táteis, o percurso passa a ser vertical e não depende de hover ou secções fixadas.

## Privacidade

A versão atual não possui formulários, analytics, cookies opcionais, mapas incorporados ou recursos externos. Fontes e efeitos visuais são fornecidos pelo próprio projeto e pelo sistema do utilizador.

Consulte `PROJECT_NOTES.md` e `CONTENT_PENDING.md` antes de qualquer publicação oficial.
